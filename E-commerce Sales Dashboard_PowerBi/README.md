# E-Commerce Sales Analysis & Dashboard

## Project Overview

This project is a **Power BI-based E-Commerce Sales Analysis and Dashboard** designed to analyze sales performance, profitability, product performance, customer trends, and regional sales.
The project uses e-commerce sales data to provide meaningful business insights through **data transformation, data modeling, DAX calculations, interactive visualizations, and dashboard development using Microsoft Power BI**.

## Objectives

* Analyze overall sales and profit performance.
* Identify top-performing products and categories.
* Understand sales performance across different regions and countries.
* Analyze monthly and yearly sales trends.
* Compare sales and profitability across different platforms.
* Create interactive dashboards for business decision-making.
* Present key business metrics through visually appealing Power BI reports.

## Report Structure

### 1. `Data`

Contains the source sales data used for analysis.

Key fields include:

* Order/Sales Information
* Product
* Category
* Country/Region
* Platform
* Sales
* Profit
* Quantity
* Order Date

### 2. `Data Transformation`

The data is prepared and transformed using **Power Query** to make it suitable for analysis.

Data preparation includes:

* Cleaning raw data.
* Handling missing or inconsistent values.
* Formatting columns and data types.
* Creating calculated fields.
* Preparing data for Power BI modeling.

### 3. `Data Model`

Contains the relationships and structured data model used in the Power BI report.

The model supports analysis of:

* Sales
* Profit
* Products
* Categories
* Regions
* Countries
* Dates
* Platforms

### 4. `Dashboard`

Contains interactive Power BI dashboards that provide a visual summary of business performance.

The dashboard includes visualizations such as:

* KPI Cards
* Bar Charts
* Column Charts
* Line Charts
* Donut Charts
* Maps
* Tables
* Interactive Filters/Slicers

## Key Findings

From the analysis:

* Identifies overall sales and profit performance.
* Highlights top-performing products and categories.
* Shows sales trends over time.
* Compares performance across different regions and countries.
* Identifies platforms and product categories contributing significantly to sales.
* Provides insights into profitable and underperforming areas.
