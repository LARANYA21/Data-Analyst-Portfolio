Bike Sales Analysis & Dashboard

Project Overview
This project is an **Excel-based Bike Sales Analysis and Dashboard** designed to explore customer demographics, purchasing behavior, and factors that influence bike purchases.
The project uses a dataset of **1,000 customer records** containing information such as gender, marital status, income, education, occupation, home ownership, number of cars, commute distance, region, age, and bike purchase status.
The workbook demonstrates practical **data cleaning, transformation, pivot table analysis, and dashboard development using Microsoft Excel**.

Objectives

* Analyze customer characteristics and bike purchasing behavior.
* Identify demographic groups with higher bike purchase rates.
* Understand the relationship between income, age, region, commute distance, and bike purchases.
* Transform raw customer data into an analysis-ready dataset.
* Create pivot tables to summarize important business metrics.
* Build an interactive-style dashboard to present insights visually.

Workbook Structure

1. `bike_buyers`

Contains the original/raw customer dataset with **1,026 records including the header** and 13 data attributes.

Key fields include:

* Customer ID
* Marital Status
* Gender
* Income
* Children
* Education
* Occupation
* Home Owner
* Cars
* Commute Distance
* Region
* Age
* Purchased Bike

2. `Working Sheet`

Contains the cleaned and transformed dataset with **1,000 customer records**.

Data preparation includes:

* Standardizing marital status and gender values.
* Preparing the dataset for analysis.
* Creating an **Age Group** classification from customer age.
* Organizing the data into a structured format suitable for pivot-table analysis.

3. `Pivot Table`

Contains summarized analysis using Excel Pivot Tables.

The pivot analysis examines metrics such as:

* Average income
* Gender
* Bike purchase status
* Overall customer income patterns

4. `Dashboard`

Contains the **Bike Sales Dashboard**, which provides a visual summary of the analysis and makes the key findings easier to interpret.

Key Findings

From the cleaned dataset:

* **1,000 customers** were analyzed.
* **481 customers purchased a bike**, representing approximately **48.1%** of the dataset.
* **519 customers did not purchase a bike**, representing approximately **51.9%**.
* The **Middle Age** customer group had the highest bike purchase rate at approximately **52.4%**.
* The **Pacific** region had the highest bike purchase rate at approximately **58.9%**.
* North America had a lower purchase rate of approximately **43.3%**.
* Female customers had a slightly higher purchase rate than male customers in this dataset.
* The analysis demonstrates how demographic and socioeconomic variables can be used to identify potential customer segments.
