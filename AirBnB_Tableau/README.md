# Airbnb Listing & Market Analysis — Tableau

## Project Overview

This project analyzes Airbnb listing and calendar data using Tableau to understand listing characteristics, pricing, availability, host information, property distribution, and geographic patterns.

The analysis combines listing-level information with calendar data to create an interactive dashboard that allows users to explore Airbnb market characteristics and identify meaningful patterns across listings and locations.

## Business Objective

The objective of this project is to analyze Airbnb marketplace data and answer questions such as:

* How are Airbnb listings distributed across different locations?
* How do listing prices vary across properties and locations?
* What property characteristics are most common among listings?
* How does availability vary across listings?
* How are bedrooms, room types, and property types distributed?
* What patterns can be observed from listing and host information?
* Which locations show notable differences in Airbnb activity and pricing?

## Dataset

The project uses Airbnb listing and calendar data.

The dataset contains information related to:

* Listing ID
* Listing name and description
* Host information
* Location and ZIP code
* Property type
* Room type
* Bedrooms and beds
* Accommodates
* Price
* Weekly and monthly pricing
* Availability
* Reviews and ratings
* Host characteristics
* Geographic information
* Calendar dates and availability

The Listings and Calendar data are joined using the listing ID.

## Tableau Analysis

The dashboard provides multiple views of the Airbnb marketplace, including analysis of:

### Listing Characteristics

Analysis of property characteristics such as:

* Bedrooms
* Property type
* Room type
* Number of beds
* Guest capacity

### Pricing Analysis

Exploration of Airbnb pricing patterns across listings and locations.

### Availability Analysis

Analysis of listing availability using calendar information to understand differences in availability across properties and locations.

### Geographic Analysis

Visualization of Airbnb listings by geographic location using location and ZIP code information.

### Host & Review Analysis

Exploration of host characteristics and review-related metrics to understand patterns among Airbnb listings.
